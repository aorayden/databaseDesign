Нужно разработать информационную систему для автоматизации оперативного функционала для гостиницы и организации данных.

#### Сущности и их атрибуты, связи:
- Номер гостиницы: 
  1. Уникальный идентификатор.
  2. Класс.
  3. Стоимость.
  4. Количество мест.

- Услуги гостиницы:
  1. Название;
  2. Описание;
  3. Стоимость.

- Постояльцы гостиницы:
  1. Номер паспорта;
  2. Дата вселения;
  3. Занимаемый номер;
  4. ФИО;
  5. Пол;
  6. Дата выселения;
  7. Признак;
  8. Оказанные услуги.

Связь между: `номер -> постоялец <- услуги`.

#### Ограничения на ввод данных:

- ФИО является обязательным к заполнению полем;
- Пол должен иметь одно из двух значений ("м" или "ж");
- Номер паспорта является обязательным к заполнению полем;
- Признак прибытия должен иметь одно из трёх значений ("не прибыл", "прибыл", "выбыл").

#### Пользователи и их функционал в системе:

- Хостес: 
  1. Управление размещением постояльцев;
  2. Проверка доступности номеров;
  3. Оперативный отчёт по местам (сколько занято и т. д.);
  4. Отчёт по местам в номерах (сколько осталось мест и т. д.);
  5. Управление прибыванием и выбыванием, просмотр текущих постояльцев.

- Администратор отеля:
  1. Управление услугами (CRUD-operations);
  2. выставление счетов по оказанным услугам и аренде номеров;
  3. контроль занятости номеров и мест в них.

- Менеджер отеля:
  1. Анализ услуг (популярность и акт об утиле);
  2. Анализ занятости номеров и мест в них;
  3. Проверка прибывших постояльцев;
  4. Обзор состояния (сколько номеров занято, сколько мест в каких номерах занято или свободно).
